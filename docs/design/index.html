Credibility mark

Study · red ↔ green · support meter

The support meter fills one segment per quarter of assessments that find the wording supported, colored on a diverging scale: red when unsupported, neutral gray when contested, green when supported. Because the number of filled segments carries the value too, the mark still reads for people who can't tell red from green. Dashed empty segments mean fewer than five assessments; unreviewed is an empty gray meter.
